# references/

Visual reference material for the project. Images, screenshots, links and our own
output.

Nothing has been collected yet. These directories are empty on purpose — do not
populate them with fabricated or remembered references. Only add material that was
actually found, made or chosen.

---

## `inspiration/`

General inspiration and related projects. Work that shares something with what we are
trying to do — in feeling, craft, interaction or idea — without necessarily being a
tree at all.

## `tree-style/`

References specifically for the 3D tree aesthetic we want. Form, materials, lighting,
level of stylization, "cuteness". This is the folder that answers "what should our tree
actually look like".

## `websites/`

Example websites and screenshots used to test whether our mapping captures different
visual personalities. Aim for genuine variety — minimal, maximalist, monochrome,
colourful, typographic, image-heavy — so the mapping is tested against real spread
rather than a set of similar sites.

## `experiments/`

Our own outputs: visual tests, explorations, and things that did not work. Keep the
failures. A tree that came out wrong usually says something specific about the mapping,
and that information is lost if only the successes are saved.

---

## Adding a reference

When adding something, note *why* it is here — the specific quality being referenced,
not just that you liked it. A reference without a reason is hard for the next person to
use.
